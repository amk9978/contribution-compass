# Support

## Usage and configuration questions

Use [GitHub Discussions](https://github.com/amk9978/contribution-compass/discussions) for setup,
configuration, MCP, customization, and design questions. Include your operating system, Python
version, command, relevant configuration with secrets removed, and the complete error message.

Before asking, check:

- the [Quick start](README.md#quick-start);
- [`contribution-compass doctor`](README.md#local-use);
- [MCP setup](docs/MCP.md); and
- existing issues and discussions.

## Bugs and feature requests

Use the repository's structured issue forms for reproducible bugs, source proposals, and feature
requests. Public issues are not a support channel for problems in projects monitored by Contribution
Compass; follow the original evidence link and use that project's own support process.

## Security and private reports

Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)
for confidential conduct reports.
